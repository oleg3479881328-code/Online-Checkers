# Online Checkers

Browser-based checkers game.

The project starts with a reliable local two-player MVP. Online multiplayer will be added only after the rules engine and board interaction are stable.

## Current phase
Bootstrap phase.

## First milestone
Build a playable local game with:
- 8×8 board
- Standard piece placement
- Turn switching
- Legal diagonal moves
- Captures
- Forced captures
- Multi-capture sequences
- King promotion
- Win detection
- Restart button
